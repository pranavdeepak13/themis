# Themis

Local manager for multiple Claude Code profiles on one macOS machine. Python 3.12, uv, Textual, textual-serve, Typer, pydantic v2, orjson, ruff, pytest. Layout and phase plan: `docs/build-prompts.md`. Decisions: `docs/DECISIONS.md`. Real data shapes: `docs/DATA_NOTES.md`.

## Rules

1. Read-only by default. Any write under a `~/.claude*` directory goes through `themis/sessions/actions.py`, `themis/resources/settings.py` or `themis/resources/symlinks.py` write functions only. Each requires an explicit confirmation token, makes a backup where the file is edited, and appends to `~/.themis/audit.log`.
2. Never read, store or display credentials: `.credentials.json`, keychain entries, env values and tokens inside MCP config or settings. Redact in `redact.py` at the reader layer so the UI cannot show them.
3. Never modify transcript files.
4. No network calls at runtime, except the user-triggered MCP health check through the `claude` CLI. Network is allowed during development to read the ARD spec and ADR.
5. Do not trust documented file schemas. Inspect real data first, write what you find to `docs/DATA_NOTES.md`, tolerate unknown fields, count unparseable lines instead of failing.
6. Stream files line by line. Do not load a full transcript into memory.
7. Real session content never enters the repo, logs, tests or commit history. Fixtures are synthetic and generated by a script. Add a pre-commit check that fails on paths matching `~/.claude*` content or on long transcript-like JSONL.
8. The core package has no UI imports. The UI never touches the filesystem directly.
9. During development, never run delete, move, edit or toggle actions against the real profile directories. Use `THEMIS_PROFILES=<tmp copy>` for write-path testing.
10. Decide without asking and record each decision in `docs/DECISIONS.md`. Stop and ask only before anything destructive on real directories.
11. Type hints everywhere, ruff clean, small modules, pytest for parsers and actions. Commit at the end of each phase with a clear message.

## Commands

```bash
uv sync                      # install deps (creates .venv)
uv run themis profiles       # list discovered profiles
uv run themis sessions       # list sessions (--profile X --sort tokens|recent|context --json)
uv run themis session <id>   # one session in detail (id prefix ok)
uv run themis scan --rebuild # rebuild the summary cache
uv run themis resources [kind] [--profile X --json]  # skills, commands, agents, hooks, mcp, plugins
uv run themis doctor         # read-only health checks
uv run themis registry manifest|search "q" [-f term=value]|inspect <urn>  # ARD v0.91 registry
uv run themis                # terminal UI (Sessions, resource sections, Compare and Doctor work; Insights is a placeholder)
uv run themis web [--port N] # same UI in the browser, 127.0.0.1 only, default port 8765
uv run pytest                # tests (synthetic fixtures only)
uv run ruff check . && uv run ruff format --check .
sh scripts/install-hooks.sh  # install the pre-commit transcript guard
```

Env: `THEMIS_PROFILES=<colon-separated dirs>` overrides discovery; `THEMIS_HOME` overrides `~/.themis` (tests use both).
